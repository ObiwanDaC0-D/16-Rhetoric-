# Rhetoric Learning Lab

A standalone, mobile-friendly GitHub Pages learning application for studying rhetoric as argument, persuasion, identity, discourse, institutional power, and ethical communication.

## Contents

- **44 frameworks** across **13 domains**, including classical rhetoric, argumentation, narrative, rhetorical criticism, critical discourse analysis, digital rhetoric, public deliberation, and risk communication.
- **Explore:** dashboard, study progress, and domain navigation.
- **Theory Library:** searchable frameworks, conceptual claims, applications, cautions, and reading leads.
- **Concept Map:** domain-organized exploration.
- **Fallacies & Cognitive Biases Lab (V5):** 24 contextual reasoning patterns, including 12 fallacy patterns and 12 cognitive biases; searchable explanations, exceptions and better-reasoning practices; eight classification exercises with legitimate counterexamples, written rewrites and JSON history export.
- **Socratic Dialogue Lab (V4):** seven questioning moves, five starter inquiries, guided dialogue turns, provisional synthesis, unresolved questions, draft persistence, saved transcripts, and JSON export. Structured prompts rather than an AI conversation.
- **Debate & Argumentation Lab (V3):** five-stage reasoning workflow (construct, challenge, steelman, respond, synthesize), evidence and assumption prompts, a completion-only reasoning checklist, local draft persistence, saved debates and JSON export. Focuses on fair reasoning rather than rhetorical victory.
- **Rhetorical Simulator (V2):** vary audience, issue frame, primary persuasive appeal, evidence quality, claims and calls to action; inspect a qualitative message architecture and ethical audit; save/revisit/export simulations and transfer a draft into Persuasion Studio.
- **Argument Builder:** Toulmin-style claim, grounds, warrant, backing, qualifier, rebuttal, and response.
- **Rhetorical Analyzer:** structured analysis of speaker, audience, exigence, ethos, pathos, logos, kairos, framing, power, and ethics.
- **Persuasion Studio:** evidence-aware, audience-centered message planning and ethical audit.
- **Social Scenarios:** five applied communication dilemmas with linked frameworks.
- **Compare:** side-by-side frameworks.
- **Recall Lab:** 16 retrieval prompts and heuristic review scheduling.
- **Study Path:** five phases from classical foundations to applied ethics.
- **Journal:** six reflection prompts.

## Deployment

The app is a single `index.html` with no build tools or external dependencies. Enable **Settings → Pages → Deploy from a branch → main → /(root)**.

Expected Pages URL: https://obiwandac0-d.github.io/16-Rhetoric-/

All saved entries use browser localStorage and are not synced across devices. Export JSON files from the individual modules to retain backups.

## Evidence and ethics

The library provides foundational reading leads, not an independently verified systematic review. Rhetorical interpretation requires contextual evidence; persuasive success does not establish truth. The application emphasizes fair counterargument, transparency, uncertainty, audience autonomy, and attention to institutional power.
